# Dictate

Hold **Right Shift**, speak, and let go. Your words are typed into whatever textbox you're in, on any app in Windows.
Change your mind mid-sentence and it keeps up: "Meet me at 8, no sorry, 7" comes out as "Meet me at 7."

## Download

**[Download Dictate-Setup.exe](https://github.com/moneymangod/dictate-releases/releases/latest/download/Dictate-Setup.exe)** (47 MB, Windows 64-bit)

## Install

1. Run `Dictate-Setup.exe` and click through. No admin rights needed.
2. Windows SmartScreen may warn you because the installer isn't code-signed yet. Click **More info**, then **Run anyway**.
3. Dictate opens. Click **Sign in with Google**. There is nothing else to set up.
4. Click into any textbox, hold **Right Shift**, speak, and let go.

Dictate lives in the system tray and can start when you log in to Windows. To remove it, go to Windows Settings → Apps.

## Good to know

- Free for now, up to 30 minutes of dictation per day.
- You need an internet connection. Your speech is sent to Dictate's servers and to Groq to be transcribed and cleaned up.
  Dictate doesn't store your audio or text; it only keeps a count of how many seconds you dictated each day.

This repository only hosts the installer. The "Source code" links GitHub adds to each release contain just this page.
